# branchlane.ch

Website meines Lern- und Portfolio-Projekts **Branchlane**.
Hier dokumentiere ich, was ich zu Infrastruktur, Automatisierung und KI aufbaue.

## Stack
- [Astro](https://astro.build) – Static Site Generator
- Hosting: Cloudflare Pages (später eigener VPS mit Docker)

## Lokal starten
npm install
npm run dev

Danach ist die Seite unter http://localhost:4321 erreichbar.
